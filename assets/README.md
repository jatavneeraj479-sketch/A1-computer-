# A1 Computer — Assets

This folder contains the visual and media assets used by the A1 Computer Portal.

## Asset Structure

- images/      → Website images
- icons/       → Icons and small graphics
- posters/     → Hero banners and promotional posters
- logos/       → Website logos
- backgrounds/ → Background images
- uploads/     → User/admin uploaded media

## Important

Keep asset filenames simple and web-friendly.

Example:

logo.png
hero-01.jpg
hero-02.jpg
service-aadhaar.png
service-student.png
notice-banner.jpg
